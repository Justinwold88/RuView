- **Docs: install RuView as a Home Assistant app.** The Home Assistant guide
  and the user guide now point Home Assistant OS users to the experimental
  [RuView app](https://github.com/Justinwold88/ruview-ha-addon) (plan item 3.1).
  The app finds the Mosquitto broker itself and keeps RuView's secure
  defaults. The user guide's 30-second flow no longer shows a Docker command
  that the image would refuse (no API token, no UDP allow-list); it links the
  guide's complete command instead.
