- **Docs: Alexa through Home Assistant.** The Home Assistant guide now shows
  how to use RuView presence in Alexa routines. Home Assistant shows Alexa a
  binary sensor as a motion sensor only for the `motion` and `presence`
  classes, and RuView's presence uses `occupancy`, so the guide adds a
  motion-class template sensor that follows it. The guide also says what Alexa
  can't see. The user guide and README link the section.
